# Betweenness centrality demo

Interactive demo of exact betweenness centrality, KADABRA's sampling and top-k mode, and BRAVA-GNN,
shown in the final talk of the lab project
[Lab-CA-SS26/Lab-CA-SS26-node-importance](https://github.com/Lab-CA-SS26/Lab-CA-SS26-node-importance).

**Live:** https://martinschlaier.com/betweenness-demo/

The files are a copy of `presentation/presentation_demo/` in that repository; everything runs in the
browser with no external dependencies.
